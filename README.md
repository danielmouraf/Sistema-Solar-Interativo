# Planetário Interativo

Sistema solar em 3D para crianças de 5 a 6 anos, com narração em português e destaque das palavras lidas.

Acesse: https://danielmouraf.github.io/Sistema-Solar-Interativo/

## O que tem

- Sol, 8 planetas, Plutão, Lua, luas de Marte, Júpiter e Saturno, cinturão de asteroides e um cometa
- Viagem guiada, experiências (rotação, translação, dia e noite, estações, fases da Lua, eclipses)
- Missões, perguntas, idade nos planetas e comparação de tamanhos
- Controle de velocidade da voz e nome de quem está aprendendo

## Tecnologia

Um único arquivo `index.html` com HTML, CSS e JavaScript. Three.js r128 (CDN jsDelivr), texturas geradas por código em Canvas e Web Speech API para a narração. Sem anúncios, sem rastreadores e sem imagens externas. O progresso fica só no `localStorage` do navegador.

## Publicação

GitHub Pages, a partir da raiz da branch `main`.
